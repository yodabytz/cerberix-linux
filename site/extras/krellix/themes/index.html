Krellix themes

Download optional themes or get a standalone copy of a bundled theme. Click a preview image to see it full size.

User install

Unpack the archive into your user theme directory, then select it under Settings > Appearance.

~/.config/krellix/themes

On Windows, put the extracted theme folder in themes beside krellix.exe.

Package install

The current Mac app includes Cheese and Bluesteel. The download-only themes below are not bundled.
