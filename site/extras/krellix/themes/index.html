Build a Krellix theme

A theme is a folder with a theme.json file and, optionally, artwork. Start with colors and type. Once those are readable, add frames, buttons, or animation without rebuilding Krellix.

Download Workbench starter Theme format reference
On this page

  • Colors, type, and sizing
  • Artwork and scaling
  • Animation
  • Mail, weather, and health artwork

1. Install your first theme

  1. Extract the Workbench ZIP, or create a folder named workbench and save the JSON below as theme.json immediately inside it.
  2. Move the whole theme folder into your user theme directory. Create the directory if it does not exist. You do not need administrator access.
  3. Open Settings > Appearance and choose workbench in the Theme list. If Settings was already open, close and reopen it to refresh the list.
Linux
~/.config/krellix/themes/. If set, use $XDG_CONFIG_HOME/krellix/themes/ instead.
macOS
~/.config/krellix/themes/. Do not modify the application bundle.
Windows
%LOCALAPPDATA%\krellix\themes\. For a portable copy, you can also use the themes folder beside krellix.exe.

The selected name comes from the folder, not the JSON metadata. Use 1–64 letters, digits, dots, underscores, or hyphens, without a leading dot. Use a new name when editing a copy of a bundled theme.

{
  "name": "workbench",
  "version": "1.0",
  "description": "A color-only starter for Krellix theme authors.",
  "colors": {
    "panel_bg": "#182725",
    "panel_border": "#39534e",
    "chart_bg": "#101b19",
    "chart_grid": "#36524c",
    "text_primary": "#effaf7",
    "text_secondary": "#b2cbc5",
    "krell_track": "#314843",
    "krell_indicator": "#69dfbf",
    "chart_line_cpu": "#69dfbf",
    "chart_line_mem": "#8ac7ff",
    "chart_line_swap": "#ffc478"
  },
  "fonts": {
    "label": { "size": 9 },
    "panel_title": { "size": 11 },
    "value": { "size": 10, "bold": true }
  },
  "metrics": {
    "panel_padding": 4,
    "panel_spacing": 2,
    "krell_height": 12,
    "meter_height": 12,
    "chart_height": 48,
    "chart_grid_lines": 4
  }
}

Use a plain-text editor. JSON needs double quotes, paired braces, and no trailing commas or comments. On Windows, check that it is theme.json, not theme.json.txt.

Iterate without restarting. Save theme.json while it is selected and Krellix reloads it. If you changed only a PNG or animation.json, save theme.json again or switch away and back. To preview without changing your usual local theme, launch krellix --instance theme-preview --theme workbench with a new instance name.

2. Set colors, type, and sizing

Panel and chart
panel_bg, panel_border, chart_bg, and chart_grid. Keep gridlines dim enough that data traces stand out.
Labels and live values
text_primary, text_secondary, text_clock, and chart_overlay. The chart overlay is the live readout drawn on the chart.
Series and gauges
Use chart_line_cpu, chart_line_mem, chart_line_swap, chart_line_net_rx, and chart_line_net_tx. krell_track and krell_indicator set the ordinary slider colors. net_krell_track and net_krell_indicator can override the Network sliders without affecting Memory or Swap.
Combined CPU charts
CPU charts use a fixed 0–100% scale. Combined charts fill from the bottom to the average usage by default, using a translucent gradient based on chart_line_cpu. Set colors.chart_fill_cpu_series to a color, a gradient, or #00000000 for outline-only charts. Use colors.chart_line_cpu_series for shades of a single base color, set metrics.chart_series_grayscale to 1 for white and light gray, or omit both for the default multicolor lines.
Fonts
Use fonts.label for ordinary text, fonts.panel_title for headings, and fonts.value where a monitor uses a value font. Font sizes are in points; family, bold, and italic are optional. Avoid depending on a font that is absent on other platforms.
Dimensions
panel_padding, panel_spacing, chart_height, and chart_grid_lines are separate metrics. Users may override dimensions in their profile.

krell_height and meter_height are base heights, not the rendered thickness. In current builds, sliders and Memory/Swap bars use two-thirds of their base height, rounded to logical pixels. A slider sprite can supply its base height. Uptime and the charts keep their own heights.

For a gradient, use an object instead of a flat color. Angle 0 runs left to right and 90 top to bottom. Prefer flat colors for text and chart traces; widgets that cannot paint gradients use the first stop. This fragment can be merged into your theme.

{
  "colors": {
    "panel_bg": {
      "gradient": "linear",
      "angle": 90,
      "stops": [[0, "#263b36"], [1, "#182725"]]
    }
  },
  "text_styles": {
    "text_primary": {
      "color": "#effaf7",
      "shadow": { "x": 0, "y": 1, "color": "#80000000" }
    }
  }
}

Qt uses #AARRGGBB for eight-digit colors: alpha comes first. A restrained shadow helps over artwork, but it does not substitute for contrast on busy backgrounds.

3. Add artwork without stretching the details

Keep portable PNG assets in an assets subfolder. Use forward slashes and exact filename case. Asset paths must be relative to theme.json; the loader rejects paths that escape the theme directory.

{
  "surfaces": {
    "panel_bg": {
      "image": "assets/panel.png",
      "slice": 4
    }
  },
  "images": {
    "chart_bg": "assets/chart.png",
    "panel_icon_cpu": "assets/cpu.png",
    "krell_track": { "image": "assets/track.png", "mode": "tile" },
    "krell": { "image": "assets/indicator.png", "frames": 1 }
  }
}
Nine-slice surfaces
slice preserves the corners and border thickness while the middle stretches. Leave room for a center in both the PNG and the rendered panel. A key in surfaces can take precedence over the matching legacy image. overlays can add artwork without stretching it with the border.
Panel icons
Use panel_icon_cpu, panel_icon_mem, or panel_icon_net to sit beside the title. Start with square transparent art and test it at the configured panel_icon_size.
Frame vs. header
frame_left and frame_right form the sides. frame_top is a tiled strip, not a banner; omit it if you do not want a repeated band. For single top artwork, use surfaces.panel_bg_top and a positive metrics.top_strip_height. For a single footer, set images.frame_bottom to an object with "mode": "stretch" and test on your target builds.
Slider sprites
images.krell can be a single moving sprite or a strip of equal-size frames. With multiple frames the current reading selects the frame; it is not a timer animation. Horizontal is the default, and "vertical": true stacks frames vertically.

4. Add motion with PNG sprite sheets

Create the static artwork first and reference it from theme.json. Export equal-size frames in one horizontal PNG strip. A sequence of 8 frames at 64 × 24 pixels produces a 512 × 24 PNG. For example, if your surfaces.panel_bg_top uses assets/header.png, create this animation.json beside theme.json:

{
  "version": 1,
  "animations": {
    "header-pulse": {
      "target": "surfaces.panel_bg_top",
      "trigger": "continuous",
      "sheet": "assets/header-strip.png",
      "fallback": "assets/header.png",
      "frame_width": 64,
      "frame_height": 24,
      "frames": 8,
      "fps": 8,
      "layout": "horizontal",
      "loop": true
    }
  }
}

Each frame must match the dimensions of the static source used by the target. The manifest must point to existing assets, including the fallback. Krellix uses the static image when animation is Off or the sheet cannot be used. Animated GIFs are not played by the theme engine; convert them to horizontal PNG sheets.

Continuous targets include surfaces.panel_bg, surfaces.panel_bg_host, surfaces.panel_bg_top, images.frame_left, images.frame_right, images.frame_bottom, and images.krell with a single static frame. mail.new uses the new_mail trigger instead. Use one entry per target, 2–120 frames, and 1–30 frames per second. Keep decoded sheets small; start at 8–12 FPS.

Try Full, Reduced, and Off under Settings > Appearance > Theme animation. The Reactor manifest also shows how top-strip motion can respond to CPU load.

5. Override mail, weather, and health icons

KrellMail
Set images.panel_icon_krellmail for idle art and images.panel_icon_krellmail_new for unread art. Use transparent PNGs. The user must choose Follow Theme in the KrellMail settings; an explicit Envelope or Tux choice stays in effect. For unread animation, target mail.new with the new_mail trigger.
KrellWeather
Use static keys such as images.panel_icon_krellweather_clear, images.panel_icon_krellweather_clear_night, or images.panel_icon_krellweather_light_rain. They apply only in Weather Theme mode and fit the existing icon slot. Missing artwork falls back to a vector icon. See the weather suffix list.
KrellHealth
Use images.panel_icon_krellhealth_heart to replace just the heart beside OK. Unlike the mail and weather overrides, this does not require a separate setting. images.panel_icon_krellhealth is separate: it decorates the Health panel title.

Make a custom KrellHealth heart

  1. Export a static transparent PNG, ideally 32 or 64 pixels square. Use a clear silhouette and trim large transparent margins, since the art is drawn in the existing small heart slot.
  2. Put it at assets/health-heart.png inside the theme folder. Merge the entry below into the existing images object in theme.json, rather than creating a second images object.
  3. Save theme.json with the theme selected. When KrellHealth reports OK, the custom image replaces the glyph and keeps its aspect ratio. Optionally set metrics.panel_icon_krellhealth_heart_size from 8 to 32 logical pixels. A larger icon can grow the healthy row without changing the label or tooltip. Omit the metric to preserve the existing slot. Save theme.json again or reselect the theme after replacing only the PNG.
{
  "images": {
    "panel_icon_krellhealth_heart": "assets/health-heart.png"
  },
  "metrics": {
    "panel_icon_krellhealth_heart_size": 26
  }
}

A missing or unreadable image keeps the original heart. Checking, warning, informational, and critical states keep their own indicators. Hover over the panel to read the full findings. Use an updated KrellHealth plugin for this key.

Dots in the examples describe where the key goes: images.panel_icon_krellmail means a panel_icon_krellmail entry inside the images object, not a dotted key in theme.json. Animation target values, by contrast, contain the dot.

6. Test and share it

  • Check narrow (120) and wide (240) panels and at least one HiDPI display. Try local and remote profiles, with both short and long labels and different monitor orders.
  • Check CPU, Network, RAM, Swap, clock, and any plugin artwork. Test motion Off, and capture a preview without private hostnames or live account details.
  • Package a single top-level folder containing theme.json, your assets, optional animation.json, and credits or license information. Keep the folder name stable when releasing updates. Do not include preferences, credentials, or absolute paths.
  • Share the ZIP or tar.gz and a preview, and list any minimum Krellix version or optional fonts. Share your creation in Krellix Discussions.

Troubleshooting

Not in the list
Check for a double-nested folder, the correct user path, and the exact filename theme.json. Reopen Settings.
Default styling appears
Validate the JSON and check for another copy with the same folder name. The user copy normally takes precedence. Start from a known-good file and add one change at a time.
Artwork or motion missing
Check filename case, asset dimensions, target name, and mode. Save theme.json again after replacing images. Run Krellix from a terminal and look for messages under krellix.theme.
