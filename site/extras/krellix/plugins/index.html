Krellix plugins

All 14 optional panels have direct downloads for Windows x64, Cerberix/Arch, Ubuntu 24.04 (amd64), and Fedora 43 and 44 (x86-64). On Linux, use the signed repositories if you want dependencies and updates handled by your package manager.

On Windows, close Krellix, extract the .zip file, and follow its README. Older standalone installers check the exact host preview listed below. Keep your newer host installed and read the compatibility notes before upgrading.

Download Krellix Windows install notes, signatures, and source archives

KrellTop

See the processes using the most CPU or memory, locally or on a remote host. Included in the current Intel Mac bundle and Windows preview.6.

Get the macOS app with KrellTop Download for Windows (preview.2) Arch tarball Ubuntu DEB Fedora RPM
