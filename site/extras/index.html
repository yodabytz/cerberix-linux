cerberix-extra

Extra apps for Cerberix.

Get Krellix, its optional plugins, and the Cerberix command-line tools through signed repositories for Cerberix/Arch, Ubuntu 24.04, and Fedora 43 and 44.

Arch / pacman Ubuntu / APT Fedora / DNF

Arch / Cerberix: pacman repository

Add the signing key once, add the repo to /etc/pacman.conf, then install packages normally with pacman.

sudo pacman-key --init
curl -s https://cerberix.org/gpg.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key 49840314FFF3DFE2D6E75439577040DEDD8E521E
[cerberix-extra]
SigLevel = Required DatabaseOptional
Server = https://repo.cerberix.org/$arch/
Add the block at the end of /etc/pacman.conf if it isn't already there. Run sudo pacman -Syu krellix to refresh and upgrade the system while installing Krellix.

Ubuntu 24.04: APT repository

For amd64. Download the signing key and the APT source file, then run these commands from the download folder. If you already configured this same URL in another APT source file, keep only one entry.

Download signing key · Download cerberix.sources

gpg --show-keys --fingerprint ./gpg.asc
sudo install -d -m 0755 /etc/apt/keyrings
sudo install -m 0644 ./gpg.asc /etc/apt/keyrings/cerberix.asc
sudo install -m 0644 ./cerberix.sources /etc/apt/sources.list.d/cerberix.sources
sudo apt update
sudo apt install krellix
Verify the fingerprint before installing the key: 4984 0314 FFF3 DFE2 D6E7 5439 5770 40DE DD8E 521E. APT uses this key only for the Cerberix source.

Fedora 43 and 44: DNF repository

For x86-64. Download the repository file, then run these commands from the download folder. DNF checks both the repository metadata and the RPM packages.

Download cerberix-fedora43.repo

sudo install -m 0644 ./cerberix-fedora43.repo /etc/yum.repos.d/cerberix-fedora43.repo
sudo dnf install krellix
When prompted, confirm that the key fingerprint is 4984 0314 FFF3 DFE2 D6E7 5439 5770 40DE DD8E 521E.

Both APT and DNF carry Krellix, its server, all 14 optional plugins, and all five command-line tools below. If you already added the repo, refresh it and install by package name, for example sudo apt install netscope or sudo dnf install netscope. The DEBs are for Ubuntu 24.04, and the RPMs are tested on Fedora 43 and 44.

Monitor

Krellix

A themeable Qt system monitor inspired by GKrellM, with remote host support, installable plugins, and downloadable themes.

Krellix page Plugins Themes
Network

Netscope

Network visibility tool for watching active connections and system network behavior from the terminal.

pacman -S netscope Ubuntu DEB Fedora RPM
Memory

Swapwatch

Swap and memory pressure watcher for keeping an eye on systems before they get sluggish.

pacman -S swapwatch Ubuntu DEB Fedora RPM
Logs

Modsentry

Monitors ModSecurity logs and displays them in a readable format.

pacman -S modsentry Ubuntu DEB Fedora RPM
Logs

Fuzzytail

Fast colorized log tailing with filtering and themes, packaged as ft.

pacman -S fuzzytail Ubuntu DEB Fedora RPM
Host

Snitch

Fail2ban helper for reporting abusive hosts and connection details from the command line.

pacman -S snitch Ubuntu DEB Fedora RPM
